# Mathematical Background

## 1. Mean-Field Game Theory

### Definition of MFG Equilibrium

A **mean-field game** (Lasry & Lions 2007; Huang, Malhamé & Caines 2006) models
a continuum of rational, identical agents each solving an optimal control problem
in which the optimality depends on the *empirical distribution* of the whole
population.

Formally, let each agent's state evolve as

```
dX_t = b(X_t, α_t, m_t) dt + σ(X_t, α_t, m_t) dW_t
```

where α_t is the agent's control, m_t is the population distribution, and W_t is
a Brownian motion.  Agent i minimises the expected cost

```
J(α) = E[ ∫_0^T f(X_t, α_t, m_t) dt  +  g(X_T, m_T) ]
```

An **MFG equilibrium** is a pair (u, m) such that:

1. **HJB equation:** u solves the Hamilton-Jacobi-Bellman equation under m.
2. **Fokker-Planck equation:** m solves the Fokker-Planck equation under the
   optimal control α*(·) implied by u.
3. **Fixed-point condition:** the distribution generated by α* equals m.

### Existence and Uniqueness: Lasry-Lions Conditions

Under the **monotonicity condition** (Lasry & Lions 2007, Theorem 2.1):

```
∫_{R^n} [ f(x, α, m₁) − f(x, α, m₂) ] (m₁(x) − m₂(x)) dx  ≥  0
```

for all probability measures m₁, m₂ and all α, the MFG system has a **unique**
classical solution (u, m).

*Interpretation:* Agents dislike crowding — the running cost increases in the
local density.  This "congestion" prevents agents from clustering, and its
monotonicity rules out multiple equilibria.

For the LOBFormationMFG we use `f(x,α,m) = c_crowd · m(x)`, which satisfies the
monotonicity condition with constant c_crowd > 0.

### Monotone Coupling

The Lasry-Lions condition is equivalent to requiring that f is *monotone* in m in
the sense of operators on probability measures.  It is a sufficient condition for
uniqueness; uniqueness can also follow from convexity arguments or small coupling.

## 2. The Coupled HJB-FP System

The MFG-LOB system takes the form:

```
−∂_t u(t,x) − (σ²/2) ∂_{xx} u
    + H(x, ∂_x u, ∂_{xx} u, m) = 0         (HJB, backward in time)

 ∂_t m(t,x) − (σ²/2) ∂_{xx} m
    + ∂_x [ b*(x, ∂_x u, m) · m ] = 0      (FP, forward in time)
```

with boundary conditions:

```
u(T, x) = g(x, m(T, ·))    (terminal cost)
m(0, x) = m₀(x)             (initial distribution)
```

### Hamiltonian

For a generic agent with control α, running cost f, drift b, diffusion σ:

```
H(x, p, M, m) = sup_{α ∈ A} { −f(x, α, m) − b(x, α, m) · p − (σ²/2) · M }
```

The supremum is achieved at **α*(x, p, m)** via the Pontryagin maximum principle:

```
∂/∂α [ −f − b · p ] = 0
```

### Nash Equilibrium

A pair (u, m) satisfying the HJB-FP system simultaneously constitutes a Nash
equilibrium: no individual agent can reduce their cost by deviating from
α*(x, ∂_x u, m), given that all others follow the same strategy.

## 3. HJB Equation: Viscosity Solutions

The HJB equation is a fully nonlinear second-order PDE.  Classical solutions may
fail to exist when characteristics cross.  The correct notion is the **viscosity
solution** (Crandall & Lions 1983).

### Definition

A function u ∈ C([0,T] × Ω) is a **viscosity solution** if:

- **Subsolution:** for every smooth test function φ touching u from above at
  (t₀, x₀), `−∂_t φ − (σ²/2) ∂_{xx} φ + H(...) ≤ 0`.
- **Supersolution:** for every φ touching u from below, the inequality is reversed.

### Comparison Principle

Under standard assumptions (bounded Lipschitz coefficients), the comparison
principle holds: if u is a subsolution and v a supersolution with u(T) ≤ v(T),
then u ≤ v throughout [0, T].  This guarantees uniqueness of the viscosity solution.

---

## 4. Fokker-Planck: Weak Solutions and Conservation

The Fokker-Planck equation is understood in the **weak sense**:

```
∫_0^T ∫ m [ ∂_t φ + (σ²/2) ∂_{xx} φ − b* ∂_x φ ] dx dt
    + ∫ m₀ φ(0,x) dx  = 0,    ∀ φ ∈ C_c^∞([0,T) × Ω)
```

### Mass Conservation

```
d/dt ∫ m(t,x) dx  = 0    ⟹    ∫ m(t,x) dx  =  1,  ∀t
```

(provided the no-flux boundary condition holds).

### Positivity

If m₀ ≥ 0, then m(t,x) ≥ 0 for all t.  The upwind numerical scheme preserves
this property exactly at the discrete level.

## 5. LOB Model Derivations

### 5.1 Avellaneda-Stoikov MFG

Starting from the stochastic control problem of a market maker with inventory
q ∈ [−Q, Q]:

- **Control:** half-spreads (δ_a, δ_b) ≥ 0
- **Execution rates:** λ(δ) = A · exp(−k · δ)
- **Running cost:** φ q² (inventory aversion) + ψ m(q) q² (crowd aversion)

In the diffusion limit, the HJB equation yields optimal half-spreads:

```
δ_a* = 1/k − (γ σ²/2) q
δ_b* = 1/k + (γ σ²/2) q
```

where 1/k is the base spread and γ σ² q/2 is the inventory skew.

### 5.2 Optimal Execution MFG

Each agent holds q ∈ [0, Q₀] and minimises:

```
J(ν) = E[ ∫_0^T (φ q_t² + ψ ν_t² + η ν_t M(t)) dt ]
```

where M(t) = ∫ ν(t,q) m(t,q) dq is aggregate execution (mean-field coupling).
The optimal rate is:

```
ν*(q, p, m) = max( (p − η M) / (2ψ), 0 )
```

The single-agent limit (η = 0) gives the **Almgren-Chriss** solution:
`q*(t) = Q₀ · sinh(κ(T−t)) / sinh(κT)`,  κ = √(φ/ψ).

### 5.3 LOB Formation MFG

Agents choose posting position x ∈ [0, x_max].  The running cost is:

```
f(x, α, m) = c_far·x + c_near·exp(−κx) + c_crowd·m(x) + c_control·α²
```

The equilibrium density m*(x) is the LOB depth profile.  The Gibbs steady-state
(σ → ∞ limit) is:

```
m*(x) ∝ exp( −[c_far·x + c_near·(exp(−κx)−1)] / (c_control·σ²) )
```

## 6. Price Impact Derivation

For the OptimalExecutionMFG, the permanent price impact of a meta-order of
size Q is:

```
ΔS(Q) = η · ∫_0^T M*(t; Q) dt
```

Empirically, many studies find ΔS(Q) ∝ √Q (the "square-root law").  The MFG
model with small σ produces nearly linear impact (δ ≈ 1); larger σ is needed
to recover δ ≈ 0.5 (Cardaliaguet & Lehalle 2018).
